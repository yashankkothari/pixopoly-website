# Pixopoly media kit

Ready-to-post pictures for Instagram and X, and the words to go with them.

| Folder | What's in it | Size |
|---|---|---|
| `logos/` | The wordmark (transparent, on dark / light / felt, white, black, gold), the stacked logo, the die, app icons | various |
| `instagram/post-01` to `post-07` | Feed posts | 1080 x 1080 and 1080 x 1350 |
| `instagram/story-01`, `story-02` | Stories | 1080 x 1920 |
| `instagram/highlights/` | Story highlight covers (Play, Pawns, Cities, Chaos, Build, News) | 1080 x 1920 |
| `instagram/profile-1080.png` | Profile picture (safe inside the circle) | 1080 x 1080 |
| `x/post-01` to `post-05` | Posts | 1600 x 900 |
| `x/header-1500x500.png` | Profile header | 1500 x 500 |
| `youtube/` | Channel banner (logo inside the phone-safe area), avatar | 2560 x 1440, 800 |
| `discord/` | Server icon, server banner, invite background | 512, 960 x 540, 1920 x 1080 |
| `facebook/` | Page cover, profile picture | 1640 x 624, 720 |
| `tiktok/`, `reddit/`, `twitch/` | Avatars and banners | various |
| `profile/avatar-400.png`, `avatar-800.png` | Profile picture with a square frame | square |
| `captions.md` | Instagram profile (name, bio options, highlights), descriptions for every platform, logo rules, a caption for every picture, a posting plan | |

`pixopoly-media-kit.zip` is all of it in one download.

The pictures are built from the game's own art by `tools/build_media_kit.py`. To change the wording on a picture, edit the text in that script and run it again.

Keep pixel art crisp: if you resize a picture, scale by a whole number with nearest-neighbour filtering.
